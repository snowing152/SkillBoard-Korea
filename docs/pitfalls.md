# Pitfalls

Mistakes already made in this repo and the rule that prevents them. When a lint rule, test or hook can
enforce the rule, move it there and delete the line here.

| Pitfall                                                                                                                                                                                                                                                                                                                                                                       | Rule                                                                                                                                                                                                                                                 |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nest build` succeeded but `dist/` was empty: an explicit `rootDir` moved `tsconfig.build.tsbuildinfo` outside `dist`, so after `deleteOutDir` tsc believed everything was already emitted.                                                                                                                                                                                   | Any tsconfig with `incremental` + `outDir` sets `tsBuildInfoFile` inside `outDir` (see `apps/api/tsconfig.build.json`).                                                                                                                              |
| A Jest test imported `@skillboard/shared` and failed with "Must use import to load ES Module".                                                                                                                                                                                                                                                                                | Keep the `moduleNameMapper` + `JEST_TS_OVERRIDES` in `apps/api/jest*.config.cjs`; do not import the shared `dist` in Jest.                                                                                                                           |
| An ESLint preset imported a package (`eslint-config-next`) that was only a dependency of the consuming app.                                                                                                                                                                                                                                                                   | Everything an `packages/config/eslint/*.mjs` file imports is a dependency of `packages/config`, not of the app.                                                                                                                                      |
| next-intl 4.14 deprecated `setRequestLocale` / `requestLocale`; older tutorials still show them.                                                                                                                                                                                                                                                                              | Locale is read once in `apps/web/src/i18n/request.ts` via `next/root-params`; pages never touch the locale param.                                                                                                                                    |
| Playwright's `iPhone 14` preset defaults to WebKit, which was not installed in CI.                                                                                                                                                                                                                                                                                            | Mobile project forces `browserName: 'chromium'`; CI installs Chromium only.                                                                                                                                                                          |
| `guard-bash` blocked a `git commit -F -` whose heredoc message merely mentioned a forbidden command; it matches the whole command text, heredocs included.                                                                                                                                                                                                                    | Write docs or commit messages that mention forbidden commands with the Write/Edit tools (or a file + `-F`), not inline in Bash.                                                                                                                      |
| A hook resolved `eslint/bin/eslint.js` with `require.resolve` and silently skipped linting: ESLint's and Prettier's `exports` maps hide their `bin/` files.                                                                                                                                                                                                                   | Hooks resolve a tool through its `package.json` `bin` field (`resolveBin` in `.claude/hooks/lib.js`); a hook that skips must say so in its output.                                                                                                   |
| `NestFactory.create(AppModule, { logger: false })` exited with code 1 and no message when env validation failed.                                                                                                                                                                                                                                                              | Scripts that boot Nest without listening pass `abortOnError: false` so the error is thrown and printed (`src/openapi/generate.ts`).                                                                                                                  |
| `process.env.X ??= default` at the top of a script ran after `AppModule` loaded, because ES imports are hoisted; env validation saw no value.                                                                                                                                                                                                                                 | Put defaults in a side-effect module imported first (`src/openapi/env-defaults.ts`), or in a Jest `setupFiles` entry.                                                                                                                                |
| Registering a global `JwtAuthGuard` silently made `/v1/health` private; only the e2e test noticed.                                                                                                                                                                                                                                                                            | Every public route carries `@Public()` and has one e2e request without a token.                                                                                                                                                                      |
| `@nestjs/jwt@12` installed fine but Jest failed with "Must use import to load ES Module": the package is ESM-only.                                                                                                                                                                                                                                                            | Before adding a dependency the API imports at runtime, check `"type"` in its package.json; Jest here runs CommonJS.                                                                                                                                  |
| Writing several interdependent files in one go made the format-lint hook report "unable to resolve" and `any` errors on the first files, because their siblings did not exist yet.                                                                                                                                                                                            | Treat those hook errors as provisional and run the package's `lint` after the batch; only errors that survive are real.                                                                                                                              |
| The phone and desktop Playwright projects ran in parallel, both created a user named "E2E Web Talent", and one got a 500: the "is this slug free?" check passed for both before either inserted.                                                                                                                                                                              | A pre-check never replaces a unique index. Insert, catch Prisma `P2002` for that column and retry (`talent-profiles.service.ts`). Parallel e2e projects are a free race detector.                                                                    |
| `<Button render={<Link />}>` (shadcn 4 / Base UI) rendered an `<a>` with `role="button"`; Playwright's `getByRole('link')` waited 30 s and the link lost its semantics for screen readers.                                                                                                                                                                                    | Links styled as buttons use `<Link className={cn(buttonVariants(...))}>`; `Button` is only for real buttons (`apps/web/CLAUDE.md`).                                                                                                                  |
| `pnpm dlx shadcn init` re-run asked interactive questions (re-install? continue?) that an agent cannot answer, and left `^` ranges in package.json.                                                                                                                                                                                                                           | Run `init` once with `-y -d --no-monorepo`; add components with `add <name> -y`; then pin the added versions exactly (tooling rule).                                                                                                                 |
| `pnpm check` passed locally but CI failed on env vars (Turborepo strict env mode, local dotenv hiding gaps).                                                                                                                                                                                                                                                                  | Run `pnpm check:ci` after touching `turbo.json`, `package.json`, workflows or env handling; list every env var a task reads in `turbo.json` / `apps/api/turbo.json`.                                                                                 |
| A layout needed the current path for `/consent?next=`, but Server Component layouts cannot read the URL; `usePathname` is client-only.                                                                                                                                                                                                                                        | `src/proxy.ts` sets the request header `x-skillboard-path` before next-intl runs and `me/layout.tsx` reads it with `headers()`; strip the locale prefix (`lib/path.ts`) and pass it through `safeNextPath` before using it as `next`.                |
| Adding a `required` checkbox made `getByRole('checkbox').first()` in an old e2e tick the wrong box, and `getByLabel(...)` on a Base UI checkbox matched two elements (the control and its hidden input).                                                                                                                                                                      | Locate checkboxes by `getByRole('checkbox', { name })`, never by position or `getByLabel`.                                                                                                                                                           |
| `z.literal(true)` for "I accept" makes the form type `true`, so an unticked box (`false`) does not type-check and `defaultValues` cannot be written.                                                                                                                                                                                                                          | The form holds a `boolean` and the resolver (the shared schema) rejects `false`; edit mode sends `true` because the flag is create-only (`talent-profile-form.tsx`).                                                                                 |
| `cn` silently dropped `text-label` when `text-muted-foreground` followed: tailwind-merge reads an unknown `text-*` as a color.                                                                                                                                                                                                                                                | A new font-size, radius, spacing or width token is also listed in the `createCn` config in `apps/web/src/lib/utils.ts`.                                                                                                                              |
| Calling `getLocale()` inside a Server Action threw "`next/root-params` ... was used inside a Server Action"; `signOut` had that bug since Phase D and no test signed out.                                                                                                                                                                                                     | A Server Action never calls `getLocale()`; the Client Component passes `useLocale()` as an argument (`signOut(locale)`, `updateAccount(input, locale)`) and the action validates it with `LocaleSchema`.                                             |
| `@Headers('user-agent')` put a required header parameter into `openapi.json`, so every generated client call demanded it.                                                                                                                                                                                                                                                     | Read request headers with a custom param decorator (`common/http/user-agent.decorator.ts`); Swagger only sees decorators it knows.                                                                                                                   |
| `ConfigService<Env, true>.get()` of an optional variable is typed `never`, so `?? default` and `Boolean()` were flagged and `undefined` was hidden.                                                                                                                                                                                                                           | Read optional variables through `optionalEnv(config, key)` (`common/config/env.ts`).                                                                                                                                                                 |
| Signing in as a seeded user sent the browser to that user's stored language (`/ru/...`), so Playwright locators by English text timed out.                                                                                                                                                                                                                                    | An e2e that asserts on English text signs up a fresh account (locale `en`) or uses a seeded user known to be `en`.                                                                                                                                   |
| The API's 10 per minute per IP auth limit returned 429 to Playwright: two viewports, one IP, a sign-in per test.                                                                                                                                                                                                                                                              | The Playwright API server sets `RATE_LIMIT_DISABLED=true` (refused in production); limits are asserted in the API e2e.                                                                                                                               |
| Deliberately revoked refresh tokens carried the same `revokedAt` as rotated ones, so the old token of a device signed out by a password change looked like a replay and revoked every session, including the one that had just changed the password.                                                                                                                          | `rotatedAt` means "used" and `revokedAt` means "ended on purpose"; only a rotated token presented again after the grace window revokes everything (`tokens.service.ts`, ADR 0024).                                                                   |
| GitGuardian flagged `newPassword: 'Other-1!x'` in a unit test as a "Generic Password": a throwaway value, but any password-shaped literal assigned to a password field looks like a secret to a scanner. It scans every commit of a PR, so a literal that was ever committed keeps the check red until the incident is resolved in the dashboard or the history is rewritten. | Tests import fake passwords and secrets from `test/fixtures/credentials.ts` of their package; only those three fixture paths are in `.gitguardian.yaml`. A new fake credential goes into the fixture, never inline.                                  |
| Login verified Google-only accounts (no password hash) against the constant-time dummy hash and trusted the result; the dummy was made from a string in the source, so that string signed in to every Google account.                                                                                                                                                         | A dummy hash for constant-time comparison is made from random bytes at boot, never from a known string, and its result is never trusted: an account without a password always fails password login (`auth.service.ts`, regression test in its spec). |
