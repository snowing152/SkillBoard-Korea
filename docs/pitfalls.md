# Pitfalls

Mistakes already made in this repo and the rule that prevents them. When a lint rule, test or hook can
enforce the rule, move it there and delete the line here.

| Pitfall                                                                                                                                                                                     | Rule                                                                                                                       |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `nest build` succeeded but `dist/` was empty: an explicit `rootDir` moved `tsconfig.build.tsbuildinfo` outside `dist`, so after `deleteOutDir` tsc believed everything was already emitted. | Any tsconfig with `incremental` + `outDir` sets `tsBuildInfoFile` inside `outDir` (see `apps/api/tsconfig.build.json`).    |
| A Jest test imported `@skillboard/shared` and failed with "Must use import to load ES Module".                                                                                              | Keep the `moduleNameMapper` + `JEST_TS_OVERRIDES` in `apps/api/jest*.config.cjs`; do not import the shared `dist` in Jest. |
| An ESLint preset imported a package (`eslint-config-next`) that was only a dependency of the consuming app.                                                                                 | Everything an `packages/config/eslint/*.mjs` file imports is a dependency of `packages/config`, not of the app.            |
| next-intl 4.14 deprecated `setRequestLocale` / `requestLocale`; older tutorials still show them.                                                                                            | Locale is read once in `apps/web/src/i18n/request.ts` via `next/root-params`; pages never touch the locale param.          |
| Playwright's `iPhone 14` preset defaults to WebKit, which was not installed in CI.                                                                                                          | Mobile project forces `browserName: 'chromium'`; CI installs Chromium only.                                                |
| `pnpm db:reset` failed for the agent: Prisma CLI detects AI agents and refuses `migrate reset` without explicit human consent.                                                              | Agents never run `db:reset`; they ask the owner. Hooks (Phase C) must not call it.                                         |
