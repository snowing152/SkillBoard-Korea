# Tech debt

Deliberate compromises. One row per shortcut; delete the row when fixed.

| What                                                                                                         | Why                                                                                                  | Risk                                                                                              | When to fix                                                  |
| ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| Free API host sleeps after idle (ADR 0013)                                                                   | $0/month                                                                                             | 30–60 s first request; no WebSockets for chat                                                     | When moving to paid hosting / before chat                    |
| TypeScript pinned to 5.9 although 7.x is out                                                                 | ts-jest, typescript-eslint and `@nestjs/swagger` do not accept TS 7 yet                              | Miss faster compiler; one day a forced migration                                                  | When those three peer ranges include 7                       |
| Nest pinned to 11.x although 12.x is out                                                                     | `nestjs-zod` peer range stops at 11                                                                  | Security patches land on 12 first                                                                 | When nestjs-zod supports 12                                  |
| `apps/api` compiles without `verbatimModuleSyntax` (ADR 0001 exception)                                      | Nest emits CommonJS; the flag forbids ESM import syntax in CJS files                                 | Type-only imports could be emitted as runtime imports; ESLint `consistent-type-imports` covers it | If Nest moves to ESM output                                  |
| Jest compiles `packages/shared` from source via `moduleNameMapper`                                           | Jest (CJS) cannot load the ESM build of shared                                                       | Shared tests and API tests use different TS settings                                              | When Jest's `require(esm)` support is stable                 |
| Local S3 is RustFS, production is Cloudflare R2                                                              | MinIO withdrew its public Docker images                                                              | Small S3 API differences; only the `StoragePort` implementation sees them                         | Never, as long as `StoragePort` tests run against both       |
| PWA icon is a single SVG, no PNG sizes, no screenshots in the manifest                                       | No design yet                                                                                        | iOS home-screen icon falls back to a screenshot                                                   | Opus design pass (Phase D+)                                  |
| `health.version` comes from `npm_package_version`, which `node dist/main.js` does not set                    | Keeps the health module dependency-free                                                              | Shows `dev` in production                                                                         | When a Dockerfile/deploy sets `APP_VERSION`                  |
| No Dockerfile for the API yet                                                                                | Hosting is chosen (Render) but not set up; Phase B only needs local boot                             | None until deploy                                                                                 | First deploy                                                 |
| `minimumReleaseAgeExclude` entries for turbo in `pnpm-workspace.yaml`                                        | pnpm 12 delays brand-new releases by default; turbo 2.11.8 was newer than the window at install time | None; pnpm manages the list                                                                       | Remove when the entries are older than the window            |
| No refresh token yet: a web session ends after `JWT_ACCESS_TTL_SECONDS` (15 min) and the user signs in again | Phase D built the minimum auth (ADR 0019)                                                            | Annoying for long edits; no "remember me"                                                         | Accounts spec (Phase E)                                      |
| `POST /v1/auth/register` records no consent and sends no verification email                                  | Needed so tests and the seed-free flow can create users                                              | Legal gap (PIPA) if deployed as is                                                                | Accounts spec, before any public launch                      |

| Public pages show Zod's wording for array limits and one generic "duplicate" message                         | Shared schemas carry no UI text; Zod locale packs translate the rest                                 | Copy is a bit technical                                                                           | Opus copy pass                                               |

| Search `q` uses `ILIKE` with no trigram or full-text index (`search` spec)                                   | Simplest correct filter; tables are tiny at launch                                                   | Sequential scans once profiles reach tens of thousands                                            | Add `pg_trgm` or FTS behind `SearchService` at ~50k rows     |
| An access token stays valid up to 15 min after account deletion or logout (`JwtAuthGuard` is stateless)      | No DB hit per request                                                                                | A stolen token works for one TTL; requests then fail with `NOT_FOUND` on the user                 | Add a revocation check or shorten the TTL when abuse appears |
